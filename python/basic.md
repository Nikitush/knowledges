## Переменные
Переменная в python имеет 3 составляющих:
- Имя переменной
- Адрес в памяти
- Значение, лежащее по этому адресу

Пример
```python
a = 5
print(id(a))
print(a)
```

Вывод
```bash
python3 ex.py
4345440688
5
```

Здесь мы видим, что переменная имеет название "a", хранится по адресу "4345440688" и имеет значение "5"
Функция `id()` показывает уникальное число - место переменной в оперативной памяти

В python есть следующие стандартные типы данных, которые могут иметь переменные:
- `int`
- `float`
- `bool`
- `str`
- `None`
- `complex`
- `bytes`
- `list`
- `tuple`
- `dict`
- `set`
- `frozenset`
- `bytearray`

Все они делятся на 2 группы - изменяемые и неизменяемые типы данных
К неизменяемым относятся:
- `int`
- `float`
- `bool`
- `str`
- `None` - уникальный тип данных, который указывает пустоту/пустое значение
- `complex`
- `bytes`
- `frozenset`
- `tuple`
К изменяемым относятся:
- `list`
- `dict`
- `set`
- `bytearray`

В чем это заключается?
Если тип данных неизменяемый, то при любых манипуляциях с переменной, которые приводят к изменению ее значения, в памяти создается новая переменная, которая будет иметь значение, полученное после изменения

Пример
```python
a = "string"
print(a)
print(id(a))
a = a.replace("s", "")
print(a)
print(id(a))
```

Вывод
```bash
python3 ex.py
string
4304731632
tring
4304681328
```

Как видим, после изменения строки она создала новый объект в памяти, поместило новое значение переменной в него и отдала нам ссылку на это место

Если тип данных изменяемый, то при любых манипуляциях с переменной, которые приводят к изменению ее значения, в памяти остается переменная, но уже с другим значением

Пример
```python
a = [1, 2]
print(a)
print(id(a))
a.append(3)
print(a)
print(id(a))
```

Вывод
```bash
python3 ex.py
[1, 2]
4371726080
[1, 2, 3]
4371726080
```

Как видим, после изменения списка объект в памяти тот же, но имеет уже новое значение переменной

## Условия
Условный оператор проверяют правдивость или ложность утверждений и в зависимости от результата реализовывают ветвление программы

Условный оператор всегда начинается с конструкции `if`, остальные могут отсутствовать

Пример
```python
a = 1
if a == 1:
	print(a)
```

Вывод
```bash
1
```

Пример неверного использования
```python
a = 1
elif a == 1:
	print(a)
```

Вывод
```bash
File "/Users/nikita/projects/pytest_skeleton/ex.py", line 3
    elif a == 1:
    ^
SyntaxError: invalid syntax
```

Для сравнения есть стандартные операторы, но можно использовать их комбинацию или иные конструкции, которые возвращают тип `bool`
Конструкции:
- `>`
- `<`
- `>=`
- `<=`
- `==`
- `is`
- `in`
- `not in`

Чтобы их комбинировать можно использовать следующие операции:
- `or`
- `and`
- `not`

**Замечание** - не стоит путать `is` и `==`, оператор `is` сравнивает не значение объектов, а их место в памяти

Пример
```python
a = [1, 2]
b = [1, 2]

if a == b:
	print("Равны")

if a is b:
	print("Одно и тоже место в памяти")
else:
	print(id(a))
	print(id(b))
	print("Места в памяти разные")
```

Вывод
```bash
python3 ex.py
Равны
4304092736
4304989312
Места в памяти разные
```

**Замечание** - но ради оптимизации разработчики `python` сделали так, что числа от `-5` до `256` всегда имеют одно и тоже место в памяти, поэтому и для них `is` вернет верное сравнение, как и по значению

`None` сделан как синглтон, так что всегда сравнение на `None` должно быть не через `==`, а через `is`

Посмотрим как может выглядеть конструкция полностью и верно по синтаксису

Пример
```python
a = 1

if a ==1:
	print("1")
elif a == 2:
	print("2")
elif a == 3:
	print("3")
else:
	print("Ничего не подошло")
```

Вывод
```bash
python3 ex.py
1
```

Здесь `if` нужен, чтобы зайти в условный оператор
Если `if` не сработал, то мы можем проверить значение на другие варианты с помощью `elif`, их количество не ограничено
Если не подошло ни одно значение, то выполнится инструкция `else`, если она есть

Есть еще так называемый **моржовый оператор** - он нужен, чтобы сразу получить значение переменной в блоке `if` и сравнить со значением

Пример
```python
if (a := 1) == 1:
	print(a)
```

Вывод
```bash
1
```

Сделать так с обычным присваиванием переменной значения не получится, будет ошибка

Пример
```python
if (a = 1) == 1:
	print(a)
```

Вывод
```bash
python3 ex.py
  File "/Users/nikita/projects/pytest_skeleton/ex.py", line 1
    if (a = 1) == 1:
          ^
SyntaxError: invalid syntax
```

 Также у условного оператора есть тернарная форма
`<значение_если_истина> if <условие> else <значение_если_ложь>`

Пример
```python
a = 1
b = 2 if a == 1 else 3
print(a, b)
```

Вывод
```bash
python3 ex.py
1 2
```

## Циклы
В python есть 2 виды циклов: `for` и `while`

**for**
Цикл `for` нужен для итерации по каким либо последовательностям или тому, из чего их можно получать

**while**
Цикл `while` исполняется, пока истино заданное условие

Пример `for`
```python
a = [1, 2, 3]
for i in a:
	print(i)
```

Вывод
```bash
python3 ex.py
1
2
3
```

Пример `while`
```python
a = 1
while a <= 3:
	print(a)
	a += 1
```

Вывод
```bash
python3 ex.py
1
2
3
```

В цикле `for`, если значение переменной не нужно, то можно его пропустить с помощью `_`, тогда мы просто проитерируемся и что-то сделаем

Пример
```python
a = [1, 2, 3]
for _ in a:
	print("Делаем что-то")
```

Вывод
```bash
python3 ex.py
Делаем что-то
Делаем что-то
Делаем что-то
```

Так же если нам нужно просто задать числовой промежуток, по которому нам надо пройтись, это можно сделать с помощью функции `range()` - она задаст отрезок и шаг, с которым по нему идти,  а потом будет отдавать получающиеся значения
Последнее указанное значение не будет входить в промежуток

Пример
```python
for i in range(1, 3):
	print(i)
```

Вывод
```bash
python3 ex.py
1
2
```

Пример с шагом
```python
for i in range(1, 5, 2):
	print(i)
```

Вывод
```bash
python3 ex.py
1
3
```

В цикле `for` может потребоваться не только значение элемента, но и его индекс, для этого используется функция `enumerate`

Пример
```python
a = [1, 2, 3]

for index, value in enumerate(a):
	print(index, value)
```

Вывод
```bash
python3 ex.py
0 1
1 2
2 3
```

Иногда бывают ситуации, когда надо пропустить какие-то шаги, тогда стоит использовать ключевое слово `continue`

Пример `for`

## Итератор
Это объект, который выдает свои элементы по одному за раз и поддерживает специальные методы `__iter__` и `__next__`(поговорим о них позже, но у всех стандартных перечислений(`list`, `str`, `tuple` и тд) они уже есть)

Например
```python
a = "abc"

it = iter(a)
print(next(it))
print(next(it))
print(next(it))
next(it)
```

Вывод
```bash
python3 ex.py
a
b
c
Traceback (most recent call last):
  File "/Users/nikita/projects/pytest_skeleton/ex.py", line 7, in <module>
    print(next(it))
StopIteration
```

Когда итерация заканчивается, получаем ошибку, как на выводе выше - это говорит о том, что закончилось перечисление, по которому мы итерировались
Это исключение стоит либо ловить(об ошибках и работе с ними поговорим позднее), либо использовать `for` для прохода по итератору

Пример обработки ошибки
```python
a = "abc"

it = iter(a)
try:
	print(next(it))
	print(next(it))
	print(next(it))
	next(it)
except StopIteration:
	print("Поймали StopIteration и обработали, все хорошо")
```

Вывод
```bash
python3 ex.py
a
b
c
Поймали StopIteration и обработали, все хорошо
```

Пример прохода с помощью `for`
```python
a = "abc"

it = iter(a)
for i in it:
	print(i)
```

Вывод
```bash
python3 ex.py
a
b
c
```

## Генератор
Специальная функция или выражение, которое создает элементы последовательности «на лету» (ленивые вычисления), а не хранит их все в оперативной памяти
Как пример, нужны чтобы хранить последовательности, которые не могут лежать полностью в оперативной памяти компьютера или генерируются по алгоритму

Для создание генератора нужно задать свою функцию, которая будет иметь ключевое слое `yield`, в отличие от `return` оно позволяет отдать значение из функции, а после выполнение кода снаружи, вернуться в тело функции для дальнейших проходов

Пример
```python
def gen():
	a = 1
	while a <= 5:
		yield a
		a += 1  

gen = gen()
print(next(gen))
print(next(gen))
print(next(gen))
print(next(gen))
print(next(gen))
next(gen
```

Вывод
```bash
python3 ex.py
1
2
3
4
5
Traceback (most recent call last):
  File "/Users/nikita/projects/pytest_skeleton/ex.py", line 14, in <module>
    print(next(gen))
StopIteration
```

Аналогично итератору вызывает исключение `StopIteration`, когда заканчивается
Либо обрабатывать, либо проходить через цикл `for`

Пример обработки ошибки
```python
def gen():
	a = 1
	while a <= 5:
		yield a
		a += 1  

gen = gen()
try:
	print(next(gen))
	print(next(gen))
	print(next(gen))
	print(next(gen))
	print(next(gen))
	next(gen)
except StopIteration:
	print("Обработали StopIteration, все хорошо")
```

Вывод
```bash
python3 ex.py
1
2
3
4
5
Обработали StopIteration, все хорошо
```

Пример прохода с помощью `for`
```python
def gen():
	a = 1
	while a <= 5:
		yield a
		a += 1

gen = gen()
for i in gen:
	print(i)
```

Вывод
```bash
python3 ex.py
1
2
3
4
5
```

## Выражение-генератор
Генераторные выражения в python — это компактный способ создания итератора, который вычисляет элементы лениво (по мере необходимости), а не хранит их все в памяти одновременно

Пример
```python
lst = (x * 2 for x in range(5) if x % 2 == 0)

print(lst)
for i in lst:
	print(i)
```

Вывод
```bash
python3 ex.py
<generator object <genexpr> at 0x104282900>
0
4
8
```

**Замечание** - не стоит путать с комперхеншен выражениями, с помощью которых можно получить `list` и `dict`

Пример
```python
lst = [x * 2 for x in range(5) if x % 2 == 0]
dct = {x: x * 2 for x in range(5) if x % 2 == 0}

print(lst)
print(dct)
```

Вывод
```bash
python3 ex.py
[0, 4, 8]
{0: 0, 2: 4, 4: 8}
```

## Функции
Функция - это именованный блок кода, который выполняет определенную задачу и может многократно вызываться в разных частях программы, дабы не писать много повторяющегося кода

Пример
```python
# Плохой пример
a = 1
b = 5
if b != 0:
	print(a / b)

b = 3
if b != 0:
	print(a / b)

b = 0
if b != 0:
	print(a / b)

# Хороший пример
def division_without_zero(a: int, b: int) -> int | float | None:
	if b != 0:
		return a / b
	else:
		return None
  
a = 1
b = 5
print(division_without_zero(a, b))
  
b = 3
print(division_without_zero(a, b))

b = 0
print(division_without_zero(a, b))
```

Вывод
```bash
python3.12 ex.py
0.2
0.3333333333333333
0.2
0.3333333333333333
None
```

У функций в python есть позиционные и именованный аргументы
Позиционные передаются в функцию строго в порядке их  записи
Пример
```python
def division_without_zero(a: int, b: int) -> int | float | None:
	if b != 0:
		return a / b
	else:
		return None

a = 1
b = 5
print(division_without_zero(a, b))
```

Вывод
```bash
python3.12 ex.py
0.2
```

Тут мы видим, что сначала передается `a`, потом  `b`

Также их можно предавать как именованные аргументы, тогда порядок будет не важен
Пример
```python
def division_without_zero(a: int, b: int) -> int | float | None:
	if b != 0:
		return a / b
	else:
		return None

a = 1
b = 5
print(division_without_zero(b=b, a=a))
```

Вывод
```bash
python3.12 ex.py
0.2
```

Видим, что несмотря на передачу не в изначальном порядке, ответ тот же, потому как теперь значения передаются конкретным параметрам функции

Два этих подхода можно использовать совместно, но соблюдая правило - сначала всегда идут позиционные аргументы, а уже потом позиционные

Пример неверный
```python
def sum_(a: int, b: int, c: int, d: int) -> int:
	return a + b + c + d

a = 1
b = 5
c = 6
d = 7

# Правильный пример
print(sum_(a, b, d=d, c=c)) 

# Неверный пример
print(sum_(d=d, c=c, a, b))
```

Вывод
```bash
python3.12 ex.py
  File "/Users/nikita/projects/pytest_skeleton/ex.py", line 13
    print(sum_(d=d, c=c, a, b))
                             ^
SyntaxError: positional argument follows keyword argument
```

Пример верный
```python
def sum_(a: int, b: int, c: int, d: int) -> int:
	return a + b + c + d

a = 1
b = 5
c = 6
d = 7
  
# Правильный пример
print(sum_(a, b, d=d, c=c))
```

Вывод
```bash
python3.12 ex.py
19
```

Это логично, потому что после того как именованные аргументы оказались впереди, дальше не ясно/не верно начинать порядковое исчисление, оно сломано

`*`, `/`, `args`, `kwargs` - про них написать далее
